# دليل هيكلة المشروع — متجرك الرقمي

موقع عربي (RTL) لعرض خدمات إنشاء المتاجر الإلكترونية، مع لوحة تحكم تحفظ البيانات في **Firebase Realtime Database** وترفع الصور إلى **ImgBB** — أي أن التغييرات تظهر لجميع الزوار فورًا.

## التقنيات
- TanStack Start + React 19 + Vite
- Tailwind CSS v4 (الإعدادات داخل `src/styles.css`)
- Firebase Realtime Database (تخزين النصوص والمشاريع)
- ImgBB (رفع صور المشاريع)
- أيقونات `lucide-react`

## هيكل الملفات
```text
src/
  routes/
    __root.tsx            الغلاف العام: <html lang="ar" dir="rtl"> + الخطوط (Cairo/Tajawal)
    index.tsx             الصفحة الرئيسية: الهيدر، الواجهة، من نحن، الخدمات، الأعمال، الفوتر
  components/site/
    AdminPanel.tsx        نافذة الدخول + هيكل لوحة التحكم (تبويبات، إشعارات، حماية من فقدان التعديلات)
    admin/
      ProjectsManager.tsx قائمة المشاريع + نموذج إضافة/تعديل + حذف بتأكيد
      PlansManager.tsx    إدارة الباقات والأسعار (إضافة، تعديل، حذف، ترتيب، إبراز باقة)
      TextsEditor.tsx     تعديل نصوص الموقع مجمّعة حسب القسم
      shared.ts           رفع الصور (مع ضغطها)، التحقق من الروابط، أنماط الحقول
  lib/
    firebase.ts           تهيئة Firebase الكسولة (يجلب الإعداد من الخادم)
    firebase.functions.ts دالة خادم تُرجع إعداد Firebase (مفتاح API يبقى في الخادم)
    site-store.ts         القيم الافتراضية + خطاف useSiteData (استماع مباشر لقاعدة البيانات)
  hooks/
    use-reveal.ts         حركات الظهور عند التمرير (IntersectionObserver)
  assets/hero.jpg         صورة الواجهة
  styles.css              الألوان والتدرجات والظلال والحركات (Design tokens)
```

## كيف تتفاعل المكونات
1. `index.tsx` يستدعي `useSiteData()` الذي يفتح مستمعين (`onValue`) على عقدتي `texts/` و `projects/` في Firebase.
2. عند أول تشغيل (قاعدة بيانات فارغة) تُزرع القيم الافتراضية تلقائيًا.
3. أي تغيير من لوحة التحكم يُكتب إلى Firebase، فيصل التحديث لكل الزوار لحظيًا دون تحديث الصفحة.

## منطق قاعدة البيانات (Firebase Realtime Database)
| العقدة | المحتوى |
|---|---|
| `texts` | كائن نصوص الموقع (العنوان، الوصف، معلومات التواصل...) |
| `projects` | مشاريع مولّدة بـ `push()`، كل مشروع `{ name, description, image, url }` |
| `plans` | الباقات، كل باقة `{ name, price, period, features[], featured, order }` |
| `meta/plansSeeded` | علامة تمنع إعادة زرع الباقات التجريبية بعد أن تحذفها كلها |

- مفتاح Firebase API محفوظ كسرّ (`GOOGLE_API_KEY`) ولا يظهر في كود المتصفح؛ تجلبه دالة خادم عند الحاجة.
- ملاحظة أمنية: تأكد من ضبط قواعد الأمان (Database Rules) في لوحة Firebase بحيث تكون الكتابة مقيّدة، فقواعد القراءة/الكتابة المفتوحة تعني أن أي شخص يمكنه تعديل البيانات.

## لوحة التحكم
- الدخول: أيقونة القفل الصغيرة في أسفل الفوتر.
- كلمة المرور: `1234` (الثابت `ADMIN_PASSWORD` في `AdminPanel.tsx`). هذه حماية شكلية فقط وليست أمانًا حقيقيًا.
- تبويب "المشاريع": إضافة، **تعديل في مكانه** (الاسم، الرابط، الوصف، واستبدال الصورة اختياريًا)، وحذف بتأكيد. التعديل يستخدم `update()` على `projects/<id>` فيبقى المفتاح نفسه ولا يُعاد النشر. تُضغط الصورة (حتى 1600px) قبل رفعها إلى ImgBB، وإن لم تُغيَّر الصورة تبقى الحالية.
- تبويب "الباقات": إضافة وتعديل وحذف الباقات، تحريكها للأعلى/الأسفل لتغيير ترتيب ظهورها، وإبراز باقة واحدة (تظهر بإطار وشارة "الأكثر طلبًا"). المميزات تُكتب سطرًا لكل ميزة. إن حُذفت كل الباقات يختفي القسم من الموقع. تُعرض في الموقع بين "الخدمات" و"أعمالنا" كشريط يُسحب جانبيًا (مع أسهم ونقاط على الحاسوب). الباقات الأولى تجريبية، عدّل أسماءها وأسعارها.
- زر واتساب العائم (أسفل يسار الشاشة): رقمه ورسالته الجاهزة يُعدّلان من تبويب "النصوص" ضمن "معلومات التواصل"، ويختفي إذا تُرك الرقم فارغًا. الرقم المحلي (07...) يُحوَّل تلقائيًا إلى الصيغة الدولية للعراق (964).
- تبويب "النصوص": النصوص مجمّعة (الواجهة، من نحن، العناوين، التواصل) مع إظهار الحقول المعدّلة وزر "تراجع".
- على الهاتف تفتح اللوحة بملء الشاشة مع أزرار كبيرة وشريط حفظ ثابت أسفل الشاشة، ويُحذَّر المستخدم قبل مغادرة نموذج فيه تعديلات غير محفوظة.

## الصيانة والتعديل
- **تغيير الألوان:** عدّل المتغيرات في `:root` داخل `src/styles.css` (`--primary`, `--primary-glow`, ...).
- **إضافة نص قابل للتعديل:** أضف الحقل إلى النوع `SiteTexts` و `DEFAULT_TEXTS` في `site-store.ts`، ثم إلى `TEXT_FIELDS` في `AdminPanel.tsx`، واستخدمه في `index.tsx`.
- **تعديل بطاقات الخدمات:** المصفوفة `SERVICES` في `index.tsx`.
- **حركة الظهور:** أضف الصنف `reveal` لأي عنصر.
- **روابط المشاريع:** كل بطاقة عبارة عن `<a target="_blank" rel="noopener noreferrer">` تفتح المتجر في تبويب جديد.
